EdisonRL is a free, browser-based builder for teaching Edison V2 robots with reinforcement learning. Users paint grid worlds, tune learning parameters, and compile robot-ready Python for EdPy—no install required.<br>
<br>
The project targets classrooms and beginners: define tile types (goals, hazards, custom costs), set start pose, export code the physical robot can run, and print large-format SVG maps. Try it: https://shreyanmitra.github.io/EdisonRL/web-builder/
