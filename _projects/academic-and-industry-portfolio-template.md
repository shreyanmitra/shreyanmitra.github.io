I extracted the engine behind my personal portfolio into a reusable Jekyll template, replacing personal content with neutral examples and adding configuration and documentation for other site owners.

Built on Academic Pages and Minimal Mistakes, the template combines a modern portfolio interface with classic layouts, publications, projects, experience, teaching, talks, blogging, and generated CV pages. It includes light/dark themes, optional equations and visualizations, and GitHub Pages deployment and validation workflows.

The website engine and **Portfolio Studio editor** are included in one repository. Users can create an independent site and customize it through content files or the local editor.

Portfolio Studio pairs a local Python server with a browser-based JavaScript interface for editing pages, collections, settings, navigation, skills, and media. Saves include an exact difference preview, stale-file checks, atomic replacement, and reversible history stored outside the website repository. The editor is excluded from the published website and does not automatically commit or deploy changes.

[Read the Portfolio Studio setup guide](https://github.com/shreyanmitra/academic-and-industry-portfolio-template/tree/main/editor).
