TeddyCodes (Teddy) wraps Claude Code with a separate `teddy` runtime: Ollama model aliases, a Teddy statusline/mascot pack, and capability-first commands for maps, memory, security, workflows, and agents.<br>
<br>
Installers for Linux/macOS and Windows leave the stock `claude` CLI untouched while provisioning Teddy-specific config under `~/.teddy/claude`, with a Python test suite and curated docs site.
