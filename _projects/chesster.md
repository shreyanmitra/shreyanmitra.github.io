Chesster lets users upload PGN game history, cleans and structures those games, and trains a bot that approximates the user’s playstyle so they can practice against themselves.<br>
<br>
The stack spans a Python backend for game processing and style learning with a JavaScript client packaged via Electron and Docker for cross-platform play on Windows, macOS, and Linux.
