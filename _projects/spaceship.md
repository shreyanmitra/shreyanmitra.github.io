Spaceship / Exo Haven is an Unreal C++ prototype where players hop between planets, gather resources, solve environmental mysteries, and eventually choose a world as humanity’s new home.<br>
<br>
The project defines planet/resource/skill data assets, runtime attribute and skill components, UE5 lighting defaults, optional Pixel Streaming, and a lightweight `WebPrototype/` for browser previews while the Unreal build matures.
