EasyMARL makes multi-agent reinforcement learning approachable: a unified Python library with 21+ MARL algorithms, vectorized environments, custom network architectures, and side-by-side algorithm comparisons.<br>
<br>
Beyond the training core, it ships a beginner-friendly web GUI, full CLI for train/eval workflows, and documentation aimed at classrooms as well as research prototyping.
